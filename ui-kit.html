RATTLEJAW UI KIT

the design system for the game and the phone controller · ui.css

RULES

1. Never write a raw colour, size or radius in a page. Use a token: var(--c-gold), var(--sp-3), var(--r-md).
2. Build every screen from the components below. A page's own CSS is for layout only (where things go), never for how a button, panel or row looks.
3. One main action per screen is a gold .ui-btn. Secondary is .ui-btn.alt. Destructive is .ui-btn.danger.
4. Controller buttons are always the PlayStation four, with the same colours everywhere: ✕ blue · ○ red · □ pink · △ green. Shoulder buttons are not used.
5. Text over the 3D game uses .ui-hud (soft shadow, no boxes). Keep it short. Show a hint only when it matters.
